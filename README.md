# Public action staging

This repository exercises a small set of pinned GitHub Actions against an
independent synthetic Python project. It contains no private source files or
research data. Its checks qualify this fixture and cannot establish whether a
different repository's protected checks or full assurance suite have passed.

The staged privacy action runs pinned scanners from the public shared standard,
with a regression fix for large Git metadata inventories. Its finding review
registry is empty. The runtime smoke test checks CPython and environment
isolation; dependency review runs on pull requests. The fixture includes one
pinned public package to exercise a dependency change. See NOTICE for the
source revision and licence.
